# Sources and credits

Every image in this directory is in the public domain. They are the source images of the README and the [gallery](../../gallery.md). The two paintings, `americangothic.jpg` and `monalisa.jpg`, are also the fixed benchmark corpus of `examples/quality.rs` and `examples/versus_go.rs` in `crates/primeval-render/`, and `monalisa.jpg` is the test fixture. Credit is not legally required for public-domain works; it is given here as a courtesy and to record where each copy came from.

To add an image, see "Gallery Images" in [`CONTRIBUTING.md`](../../../CONTRIBUTING.md), and add its entry here.
